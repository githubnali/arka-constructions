# ARKA homepage

## Stack and visual system
React 19, TypeScript, Vinext/Vite (Next-compatible app structure), custom CSS, Lucide icons, Sites hosting starter. Headings: Outfit. Body: DM Sans. Navy #102A35, gold #C5A269, ivory #F7F6F2, white #FFFFFF, muted text #667176.

## Content and launch review
Services, proprietor name, client references, business contacts and strengths are from the supplied ARKA company profile. The PDF is not published because it contains personal identifiers. Extracted logo in public/images is a reference; the header uses a proposed typographic mark.

Confirm the requested 'Best' headline and Chennai coverage before public release. Experience years and engineering qualifications are not supplied. The founder uses initials until a verified portrait is available. Project cards are work categories with clearly labelled illustrative photographs, not invented case studies. Ongoing projects use an honest enquiry state.

Essential, Premium and Signature are explicitly proposed planning options, not priced offers. Confirm actual specifications, exclusions, taxes and rates. The approach is an editorial workflow inferred from the profile and needs business confirmation.

## Features
Sticky navigation, mobile menu/contact bar, completed/ongoing tabs with keyboard support, service details, package details, native FAQ accordions, accessible dialogs, reduced-motion support, contact and map links. Navigation targets homepage sections; standalone pages are outside this implementation.

Quote form validates fields and prepares an email draft. The user must open their email app and send it. No server lead storage, automatic sending, CMS or analytics is connected. Add these separately when requirements are agreed. No user details enter source control.
